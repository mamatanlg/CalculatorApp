# Calculator

A responsive calculator web app built with Expo, React Native, and React Native Web.

## Author

- **Name:** Louis Gabriel Mamatan
- **Course:** BSIT-3T2

## Run in a web browser

1. Install [Node.js](https://nodejs.org/) if it is not already installed.
2. In a terminal, open this project folder.
3. Install the project dependencies:

   ```sh
   npm install
   ```

4. Start Expo Web:

   ```sh
   npx expo start --web
   ```

Expo opens the calculator in your browser. No phone, Expo Go, or emulator is needed.

## Tests

Run the calculator parser tests with:

```sh
npm test
```
